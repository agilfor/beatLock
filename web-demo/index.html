Welcome to beatLock!

beatLock is a project by agilfor that tries to make your password a bit more secure.

To try it, type in any password in any rhythm you like (feel free to vary pauses, speed, etc). If all works, you should only be able to authenticate by retyping the same password with the same rhythm as originally.

Note that this is only a web demo (there is no actual security lol). The goal is to make this a PAM module that can be used on Linux devices.
